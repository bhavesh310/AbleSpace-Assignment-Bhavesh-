
# AbleSpace QA Testing Assignment

## Overview
This repository contains the QA testing assignment completed for AbleSpace. It includes exploratory testing, detailed test cases, bug reports, compatibility testing, and a final test summary based on observations from the staging application.

## Repository Contents

| File / Folder | Description |
|---|---|
| `01_exploratory_testing.md` | Exploratory testing scenarios, observations, and results |
| `02_detailed_test_cases.md` | Detailed test cases with steps and expected results |
| `03_bug_reports.md` | Identified bugs, severity, priority, and reproduction steps |
| `04_compatibility_report.md` | Browser compatibility and responsive layout observations |
| `05_test_summary.md` | Overall testing summary and conclusions |
| `evidence/` | Screenshots and supporting evidence for test results |

## Testing Scope
- User registration and login
- Student / Caseload management
- Calendar navigation and event visibility
- Data logging and validation
- Accommodations module
- Service Time sorting
- Responsive layout checks on mobile and tablet viewports

## Testing Approach
- Manual exploratory testing
- Functional testing
- Positive and negative test scenarios
- Data persistence checks after page refresh
- Basic responsive and browser compatibility checks

## Bug Reporting
Reported issues include reproduction steps, expected behavior, actual behavior, and severity or priority where applicable. Potential issues that require further confirmation are identified separately from confirmed defects.

## Test Environment
- Application: AbleSpace staging environment
- Browser: Google Chrome
- Testing type: Manual QA testing

## Evidence
Relevant screenshots should be placed in the `evidence/` folder and referenced in the corresponding test case or bug report.

## Notes
This submission reflects the features and behaviors observed during the testing session. Browsers, devices, and scenarios not actually tested are not considered verified.
